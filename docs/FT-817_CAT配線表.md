# FT-817 / FT-818 CAT 配線表（USB-TTL シリアルケーブル）

wfview-win の FT-817 / FT-818 画面で使う CAT ケーブルの配線です。
対象ケーブル：CH340 チップの USB-TTL ケーブル（4 本線、先端がメスのジャンパーピン）
[Amazon B0D1L9KXF4](https://www.amazon.co.jp/dp/B0D1L9KXF4)

## 配線表

| USB ケーブルの線色 | ケーブル側の信号 | 向き | FT-817 ACC ピン | FT-817 側の信号 |
|---|---|---|---|---|
| **緑** | TXD（USB シリアルからの送信） | → | **5 番** | RX D（無線機への CAT 入力） |
| **白** | RXD（USB シリアルの受信） | ← | **4 番** | TX D（無線機からの CAT 出力） |
| **黒** | GND | ― | **3 番** | GND |
| **赤** | +5V 電源 | **接続しない**（先端を絶縁） | ― | ― |

ACC の 1 番（+13.8V）、2 番（TX GND）、6 番（BAND DATA）、7 番（ALC）、8 番（TX INH）は接続しません。

- **1 番は +13.8V の出力です。** ケーブルの線に触れると、ケーブルを壊すおそれがあります。
- **2 番「TX GND」はリニアアンプ用の送信制御出力で、アースではありません。** アースには 3 番を使います。
- **赤（+5V）は FT-817 のどのピンにもつながないでください。** FT-817 は自分の電源で動くため不要です。

## ACC 端子のピン位置（FT-817 背面のジャックを正面から見た図）

```
        8 TX INH   7 ALC   6 BAND DATA
        5 RX D     4 TX D  3 GND
           2 TX GND     1 +13.8V
```

プラグにはんだ付けするときは、はんだ付け面から見ると左右が反転します。

## 接続前の確認（テスター）

1. USB ケーブルを PC に挿し、**黒と赤の間が約 +5V**（製品によっては 3.3V）になることを確認します。
2. 黒と緑、黒と白の間は、どちらも待機中 High（3〜5V 程度）になります。

## wfview-win 側の設定

1. 設定画面でメーカーに **Yaesu** を選びます。
2. 機種に「**FT-817 / 817ND (USB serial CAT)**」または「**FT-818 (USB serial CAT)**」を選びます。
3. COM ポートに、このケーブルの COM 番号を指定します。
4. ボーレートを、無線機の CAT RATE メニューと同じ値（4800 / 9600 / 38400）にします。
5. 接続すると FT-817 画面に切り替わり、LCD に周波数が表示されれば通信できています。
