# wfview-win 操作説明書

更新日: 2026-07-12

## 1. 概要

`wfview-win` は、Windows から対応無線機を制御するためのアプリケーションです。
周波数、VFO、送受信、チューナー、CW、レピータ / スプリット、メモリー、スペクトラム / ウォーターフォール表示を操作できます。

この操作説明書では、このリポジトリの Windows 版で追加・調整された操作を中心に説明します。
左側の目次をクリックすると、該当する説明へジャンプできます。

## 2. 起動と接続

1. `wfview-win.exe` を起動します（スタートメニューまたはインストール先フォルダから）。起動時はメイン画面が最大化されます。
2. `Settings` を開き、無線機、接続方式、ポート、CI-V アドレス、音声入出力などを設定します。
3. `Connect` を押して無線機に接続します。
4. 無線機がリモート電源制御に対応している場合は、`Power On` で電源を入れます。
5. 終了時は必要に応じて `Power Off` を押してからアプリを閉じます。

接続後、無線機の対応機能に応じてボタンや設定項目が有効になります。対応していない機能は非表示または無効になります。

### 2.1 接続プロファイル

Settings の `Connection Profile` では、無線機ごとの接続設定を名前付きプロファイルとして複数保存できます。
自宅 LAN、リモート接続、USB シリアル接続などを切り替える場合に使用します。

主な操作:

- プロファイル名を入力して `Save` を押すと、現在の接続設定を保存します。
- 既存プロファイルを選択すると、保存されている接続情報が入力欄へコピー表示されます。
- 同じ名前で `Save` を押すと、そのプロファイルを上書きします。
- `Delete` を押すと、選択中のプロファイルを削除します。
- `Connect` を押すと、選択中の保存済みプロファイルを読み込み直してから接続します。

保存される主な項目:

- メーカー、CI-V アドレス、PTT 種別。
- シリアルポート、ボーレート、仮想シリアルポート。
- LAN 有効 / 無効、IP アドレス、Control / CAT / Audio / Scope ポート。
- 接続タイプ、ユーザー名、管理者ログイン、Half Duplex。
- 音声入出力、サンプルレート、コーデック、レイテンシ。

注意:

- プロファイルを選択しただけでは無線機へ接続しません。接続するには `Connect` を押します。
- 入力欄を変更した後にその内容を残したい場合は、プロファイル名を確認して `Save` を押してください。
- パスワードはプロファイルに保存されます。共有 PC では取り扱いに注意してください。

## 3. メイン画面の主なボタン

| ボタン | 用途 |
|---|---|
| `Power On` | 対応無線機の電源を入れます。 |
| `Power Off` | 対応無線機の電源を切ります。 |
| `送信` | 送信 / 受信を切り替えます。ボタン背景は薄緑色です。送信中は表示が `送信中` になり、文字が赤になります。 |
| `Enable ATU` | オートアンテナチューナーを有効 / 無効にします。 |
| `TUNE` | オートアンテナチューナーのチューニングを開始します。 |
| `CW` | CW 送信ウィンドウを開きます。 |
| `Rpt/Split` | レピータ、トーン、スプリット関連の設定画面を開きます。 |
| `Memories` | メモリー画面を開きます。 |
| `Split` | 対応機種でスプリット動作を切り替えます。 |

画面下部のボタン列（`Connect` の右）には `ヘルプ` ボタンがあります。
押すとこの操作説明書が別ウィンドウで開き、左の目次から各項目へジャンプできます。

`終了` ボタンは誤操作防止のため **ダブルクリック** で実行され、シングルクリックでは反応しません。

### 3.1 メータ表示

S メータの下に、SWR メータと Tx(dBfs) メータ（マイク入力レベル相当）が常時表示されます。

| メータ | 内容 |
|---|---|
| S メータ | 受信信号強度を表示します。 |
| SWR | 送信時のアンテナ VSWR を表示します。目盛りの赤い部分は高 SWR を示します。 |
| Tx(dBfs) | 送信時のマイク / 変調入力の音声レベルを dBFS で表示します。振り過ぎ（0 dBFS 付近）に注意してください。 |

2 段目・3 段目のメータは SWR / Tx(dBfs) に固定されており、`Settings` 画面の該当プルダウンは
無効表示になっています。接続する無線機やプロトコルによっては、一部のメータに値が
表示されない場合があります。

## 4. 周波数操作

### 4.1 周波数表示の桁クリック

周波数表示の任意の桁をクリックすると、その桁が周波数アップ / ダウンのステップになります。

例:

- 1 Hz の桁をクリック: `▲` / `▼` は 1 Hz ステップになります。
- 100 Hz の桁をクリック: `▲` / `▼` は 100 Hz ステップになります。
- 1 kHz の桁をクリック: `▲` / `▼` は 1 kHz ステップになります。

従来のダイアル下のステップ周波数プルダウンは表示されません。ステップ選択は周波数表示の桁クリックで行います。

### 4.2 VFO 横の周波数アップ / ダウンボタン

VFO A / B 表示の横に、周波数ダウン `▼` と周波数アップ `▲` ボタンがあります。

- `▼`: 選択中の桁ステップ分だけ周波数を下げます。
- `▲`: 選択中の桁ステップ分だけ周波数を上げます。

最後にクリックした周波数表示の桁が、これらのボタンのステップ幅になります。
`▼` / `▲` を押したままにすると、選択中のステップ幅で連続して周波数が変化します。
周波数ロック中は `▼` / `▲` ボタンがグレーアウトし、周波数変更はできません。

### 4.3 周波数入力とバンド選択ポップアップ

周波数入力ポップアップとバンド選択ポップアップは、メイン画面上で扱いやすいように小型化されています。
バンド選択ボタンもコンパクトなサイズで表示されます。

### 4.4 VFO 操作

- `VFO A` / `VFO B`: 操作対象 VFO を切り替えます。
- `A<>B`: VFO A と VFO B を入れ替えます。
- `A=B`: VFO A と VFO B を同じ周波数 / モードにします。
- `V/M`: VFO / メモリーモードを切り替えます。
- `SPLIT`: スプリット動作を切り替えます。

表示されるボタンは、接続した無線機の対応機能によって変わります。

## 5. ウォーターフォールとスコープ

### 5.1 WF スライダー

RF / AF / SQL などの縦スライダー群に `WF` スライダーがあります。
このスライダーでウォーターフォールの色レベルを調整します。

- 上げる: ウォーターフォールの表示レベルを上げます。
- 下げる: ウォーターフォールの表示レベルを下げます。
- 値は保存され、次回起動時にも反映されます。

### 5.2 スコープ操作

スコープエリアでは、モード、スパン、エッジ、ホールド、ピーククリアなどを操作できます。
ウォーターフォールやスペクトラムの表示内容は、無線機のスコープ対応状況と設定に依存します。

## 6. 送信関連操作

### 6.1 送信

`送信` ボタンを押すと送信状態になります。送信中はボタン表示が `送信中` になります。
もう一度押すと受信状態に戻ります。

`送信` ボタンは通常時も薄緑色の背景で表示されます。送信中は `送信中` の文字が赤く表示されるため、送信状態を画面上で確認しやすくなっています。

送信する前に、以下を確認してください。

- 周波数とバンドが正しいこと。
- モードが正しいこと。
- アンテナまたはダミーロードが適切に接続されていること。
- 送信出力が意図した値であること。
- 無線局の運用条件に合っていること。

### 6.2 TUNE

`Enable ATU` を有効にしてから `TUNE` を押すと、対応無線機でオートアンテナチューナーのチューニングを開始します。
チューニング時は送信状態になることがあるため、必ず接続先と出力条件を確認してください。

### 6.3 CW

`CW` を押すと CW 送信ウィンドウを開きます。
マクロやテキスト送信を行う場合は、送信前に速度、サイドトーン、送信先 VFO、モードを確認してください。

## 7. レピータ / スプリット

`Rpt/Split` を押すと、レピータ、トーン、オフセット、スプリット関連の設定画面を開きます。

主な用途:

- レピータ用のオフセット設定。
- トーン / TSQL / DTCS などの設定。
- 送信周波数の設定。
- クイックスプリットの設定。

無線機によって対応範囲が異なります。

## 8. メモリーモード

`Memories` を押すとメモリー画面を開きます。
無線機がメモリー読み書きに対応している場合、メモリーチャンネルの読み出し、保存、呼び出しなどを行えます。

VFO 表示部の `V/M` ボタンが表示されている場合は、VFO モードとメモリーモードを切り替えられます。

## 9. 終了

1. 必要に応じて送信状態を解除します。
2. 必要に応じて `Power Off` を押します。
3. `終了` ボタンを**ダブルクリック**するか、ウィンドウを閉じてアプリケーションを終了します。
   `終了` ボタンは誤操作防止のためシングルクリックでは反応しません。

この版では、終了時に発生していた Qt audio 系のクラッシュを回避する修正が入っています。

## 10. トラブルシューティング

| 症状 | 確認すること |
|---|---|
| 接続できない | 無線機、接続方式、ポート、CI-V アドレス、ネットワーク設定を確認します。 |
| ボタンが無効 | 無線機がそのコマンドに対応しているか確認します。 |
| 周波数アップ / ダウンのステップが意図と違う | 周波数表示の目的の桁をクリックしてから `▲` / `▼` を押します。 |
| WF レベルが合わない | `WF` スライダーでウォーターフォール表示を調整します。 |
| 音声が入出力されない | `Settings` の音声入力 / 出力デバイスと Windows のプライバシー設定（マイクへのアクセス許可）を確認します。 |
| TUNE が動作しない | `Enable ATU`、無線機のチューナー対応、送信条件を確認します。 |

## 11. 安全上の注意

このアプリは無線機を送信状態にできるソフトウェアです。
送信、TUNE、CW、スプリット、レピータ設定を操作する前に、必ず周波数、出力、アンテナ、免許条件、周囲への影響を確認してください。
