# wfview-win 操作説明書

更新日: 2026-07-12（Settings 画面構成 / 初回起動ウィザード / 戻るボタン / AF-システム音量連携 等を追記）

## 1. 概要

`wfview-win` は、Windows から対応無線機を制御するためのアプリケーションです。
周波数、VFO、送受信、チューナー、CW、レピータ / スプリット、メモリー、スペクトラム / ウォーターフォール表示を操作できます。

この操作説明書では、このリポジトリの Windows 版で追加・調整された操作を中心に説明します。
左側の目次をクリックすると、該当する説明へジャンプできます。

## 2. 起動と接続

1. `wfview-win.exe` を起動します（スタートメニューまたはインストール先フォルダから）。起動時はメイン画面が最大化されます。
2. `Settings` を開き、無線機、接続方式、ポート、CI-V アドレス、音声入出力などを設定します。
3. `Connect` を押して無線機に接続します。
4. 無線機がリモート電源制御に対応している場合は、`Power On` で電源を入れます。
5. 終了時は必要に応じて `Power Off` を押してからアプリを閉じます。

接続後、無線機の対応機能に応じてボタンや設定項目が有効になります。対応していない機能は非表示または無効になります。

### 2.0 初回起動時のセットアップウィザード

インストール後、初めて `wfview-win.exe` を起動したときは、通常のメイン画面より先に
`First Time Setup`（英語表示）ウィザードが自動的に表示されます。

- `How is your radio connected?` で無線機の接続方法（PC 上のシリアルポート、ネットワーク経由など）を選びます。
- ウィザードから `Settings` 画面を開いて詳細設定を行うか、設定をスキップして後で `Settings` から設定することもできます。
- ウィザードからアプリを終了することもできます。
- 一度セットアップを完了（またはスキップ）すると、次回以降の起動ではこのウィザードは表示されず、通常どおりメイン画面が開きます。

### 2.1 接続プロファイル

Settings の `Connection Profile` では、無線機ごとの接続設定を名前付きプロファイルとして複数保存できます。
自宅 LAN、リモート接続、USB シリアル接続などを切り替える場合に使用します。

主な操作:

- プロファイル名を入力して `Save` を押すと、現在の接続設定を保存します。
- 既存プロファイルを選択すると、保存されている接続情報が入力欄へコピー表示されます。
- 同じ名前で `Save` を押すと、そのプロファイルを上書きします。
- `Delete` を押すと、選択中のプロファイルを削除します。
- `Connect` を押すと、画面に表示されている現在の設定で接続します。

保存される主な項目:

- メーカー、CI-V アドレス、PTT 種別。
- シリアルポート、ボーレート、仮想シリアルポート。
- LAN 有効 / 無効、IP アドレス、Control / CAT / Audio / Scope ポート。
- 接続タイプ、ユーザー名、管理者ログイン、Half Duplex。
- 音声入出力、サンプルレート、コーデック、レイテンシ。

注意:

- プロファイルを選択しただけでは無線機へ接続しません。接続するには `Connect` を押します。
- 入力欄を変更した後にその内容を残したい場合は、プロファイル名を確認して `Save` を押してください。
- パスワードはプロファイルに保存されます。共有 PC では取り扱いに注意してください。
- CI-V アドレスなどの入力欄を編集した直後でも、`Save` / `Connect` を押した時点でその内容が確定されて保存・接続に使われます（フォーカスを他の欄に移す操作は不要です）。
- `Connect` は選択中プロファイルを保存済みの内容で読み込み直したりはしません。プロファイル選択後に IP アドレスやポートなどを手で修正した場合、その修正値のまま接続されます。

### 2.2 Settings 画面の構成

`Settings` 画面は左側のリストで切り替える 7 つのカテゴリに分かれています。

| カテゴリ | ショートカット |
|---|---|
| Radio Access | Shift+F1 |
| User Interface | Shift+F2 |
| Radio Settings | Shift+F3 |
| Radio Server | Shift+F4 |
| External Control | Shift+F5 |
| DX Cluster | Shift+F6 |
| Experimental | Shift+F7 |

主な設定項目:

- **CI-V アドレス**: プルダウン（コンボボックス）形式です。選択したメーカー（Icom / Kenwood / Yaesu）の機種一覧から選ぶか、直接 16 進数で入力することもできます。値が `0`（自動）の間は "auto" と表示され、選択欄は無効表示になります。
- **Icom 選択時の Control / CAT / Audio / Scope ポート欄**: Icom プロトコルでは、実際に使われるのは Control ポートのみです。CAT / Audio ポートの欄はログイン応答でサーバー側（無線機/wfserver）から通知される値を参考表示しているだけで、ここを編集しても動作には反映されません（Scope ポート欄は Icom では非表示です）。
- 音声デバイス、サンプルレート、コーデック、レイテンシなどは `Radio Server` / `User Interface` カテゴリにまとまっています。

| `Split` | 対応機種でスプリット動作を切り替えます。 |

### 3.0 画面最下部のボタン列

メイン画面の最下部には、左から右へ次のボタンが並んでいます。

| ボタン | 用途 |
|---|---|
| `Settings` | 設定画面を開きます。 |
| `保存` | 現在の設定を保存します。 |
| `ステータス` | 無線機の接続ステータス画面を開きます。 |
| `Log` | 交信ログ画面を開きます。 |
| `Bands` | バンド選択ボタンの画面を開きます。 |
| `周波数設定` | 周波数入力画面を開きます。 |
| `Rig Edit` | 無線機定義ファイル（.rig）の編集画面を開きます。 |
| `TX音声処理` | 送信音声処理（イコライザー / コンプレッサー等）の設定画面を開きます。無線機に接続し、対応している場合のみ有効になります。 |
| `RX音声処理` | 受信音声処理の設定画面を開きます。無線機に接続し、対応している場合のみ有効になります。 |

`終了` ボタンは誤操作防止のため **ダブルクリック** で実行され、シングルクリックでは反応しません。

### 3.1 メータ表示

S メータの下に、SWR メータと Tx(dBfs) メータ（マイク入力レベル相当）が常時表示されます。

| メータ | 内容 |
|---|---|
| S メータ | 受信信号強度を表示します。 |
| SWR | 送信時のアンテナ VSWR を表示します。目盛りの赤い部分は高 SWR を示します。 |
| Tx(dBfs) | 送信時のマイク / 変調入力の音声レベルを dBFS で表示します。振り過ぎ（0 dBFS 付近）に注意してください。 |

2 段目・3 段目のメータは SWR / Tx(dBfs) に固定されており、`Settings` 画面の該当プルダウンは
無効表示になっています。接続する無線機やプロトコルによっては、一部のメータに値が
表示されない場合があります。

### 3.2 AF スライダーと Windows のシステム音量

Windows 版では、AF（音量）スライダーを操作すると、アプリ内の受信音量と連動して
Windows の既定の出力デバイスのシステム音量（マスターボリューム）も同じ割合で変化します。
AF スライダーを最大にするとシステム音量も最大になり、中間の値でも比例して変化します。
無線機によってスライダーの範囲が異なりますが、範囲に応じて正しく比例するようになっています。

### 3.3 変調入力スライダーのラベル表示

変調入力レベルのスライダーのラベルは、無線機側の入力名が `USB` の場合に限り
`MD`（変調度）と表示されます。それ以外の入力名はそのまま表示されます。

### 3.4 各ウィンドウの「戻る」ボタン

`Log`、`Bands`、`周波数設定`、`CW`、`Rpt/Split`、`Memories`、`TX音声処理`、`RX音声処理` の
各ウィンドウには、左上（またはウィンドウ上部）に `← 戻る` ボタンがあります。
押すとそのウィンドウを閉じてメイン画面に戻ります。ウィンドウの `×` で閉じることもできます。

## 4. 周波数操作

### 4.1 周波数表示の桁クリック

周波数表示の任意の桁をクリックすると、その桁が周波数アップ / ダウンのステップになります。

例:

- 1 Hz の桁をクリック: `▲` / `▼` は 1 Hz ステップになります。
- 100 Hz の桁をクリック: `▲` / `▼` は 100 Hz ステップになります。
- 1 kHz の桁をクリック: `▲` / `▼` は 1 kHz ステップになります。

従来のダイアル下のステップ周波数プルダウンは表示されません。ステップ選択は周波数表示の桁クリックで行います。

### 4.2 VFO 横の周波数アップ / ダウンボタン

VFO A / B 表示の横に、周波数ダウン `▼` と周波数アップ `▲` ボタンがあります。

- `▼`: 選択中の桁ステップ分だけ周波数を下げます。
- `▲`: 選択中の桁ステップ分だけ周波数を上げます。

最後にクリックした周波数表示の桁が、これらのボタンのステップ幅になります。
`▼` / `▲` を押したままにすると、選択中のステップ幅で連続して周波数が変化します。
周波数ロック中は `▼` / `▲` ボタンがグレーアウトし、周波数変更はできません。

### 4.3 周波数入力とバンド選択ポップアップ

周波数入力ポップアップとバンド選択ポップアップは、メイン画面上で扱いやすいように小型化されています。
バンド選択ボタンもコンパクトなサイズで表示されます。

### 4.4 VFO 操作

- `VFO A` / `VFO B`: 操作対象 VFO を切り替えます。
- `A<>B`: VFO A と VFO B を入れ替えます。
- `A=B`: VFO A と VFO B を同じ周波数 / モードにします。
- `V/M`: VFO / メモリーモードを切り替えます。
- `SPLIT`: スプリット動作を切り替えます。

表示されるボタンは、接続した無線機の対応機能によって変わります。

## 5. ウォーターフォールとスコープ

### 5.1 WF スライダー

RF / AF / SQL などの縦スライダー群に `WF` スライダーがあります。
このスライダーでウォーターフォールの色レベルを調整します。

- 上げる: ウォーターフォールの表示レベルを上げます。
- 下げる: ウォーターフォールの表示レベルを下げます。
- 値は保存され、次回起動時にも反映されます。

### 5.2 メイン画面のスコープ関連ボタン

| ボタン | 用途 |
|---|---|
| `Dual Watch` | デュアルウォッチを切り替えます（対応機種のみ表示）。 |
| `Dual Scope` | メイン / サブ両方のスコープを同時表示します。対応機種では無線機側の機能を使用し、非対応機種（IC-9700 等）ではアプリ側で表示を切り替えます。 |
| `Main/Sub` | 操作対象を Main バンドと Sub バンドの間で切り替えます（対応機種のみ）。 |
| `Split` | スプリット動作を切り替えます。 |
| `Swap` | Main と Sub の内容を入れ替えます（対応機種のみ表示）。 |
| `Main=Sub` | Main の内容を Sub にコピーします（対応機種のみ表示）。 |

### 5.3 スコープ / ウォーターフォールの詳細操作

スコープ・ウォーターフォールの実体は受信機ごとの表示ウィジェットにあります。主なコントロール:

- `Spectrum Mode` コンボ: スコープの表示モードを選択します（選べるモードは機種によって異なります）。選んだモードに応じて、以下の Span 系または Edge 系のコントロールが表示されます。
- `Span` コンボ（Center / Scroll-C モード時に表示）: 表示帯域幅を選択します。
- `Fixed Edge` コンボ（Fixed / Scroll-F モード時に表示、1〜4）: あらかじめ登録した 4 つの周波数範囲（エッジ）から選択します。
- `Custom Edge` ボタン: ダイアログで開始・終了周波数（MHz）を入力し、選択中の Edge スロットを上書きします。
- `To Fixed` ボタン: Center モードで表示中の周波数範囲を保ったまま、選んだ Edge スロット（1〜4）に書き込んで Fixed モードへ変換します。選択したスロットの内容は上書きされます。
- `HOLD` ボタン: スコープ表示のホールド（一時停止）を切り替えます（対応機種のみ表示）。
- `Clear Peaks` ボタン: ピークホールド表示をクリアします（対応機種のみ表示）。
- `Detach` ボタン: スコープをメイン画面から切り離して独立したウィンドウにします（もう一度押すと再結合）。
- `◀`（Configure Scope）ボタン: 詳細設定パネルの開閉を切り替えます。

`◀` で開く詳細設定パネル:

| 項目 | 内容 |
|---|---|
| `Ref` | 表示リファレンスレベル |
| `Length` | ウォーターフォール表示履歴の長さ |
| `Ceiling` / `Floor` | スペクトラム表示の上限・下限レベル |
| `Waterfall Speed` | ウォーターフォールが流れる速さ（Fast / Mid / Slow） |
| `Waterfall Theme` | ウォーターフォールの配色（Jet / Cold / Hot / Therm / Night / Ion / Gray / Geo / Hues / Polar / Spect / Candy） |
| `PBT Inner` / `PBT Outer` | パスバンドチューニング（対応機種のみ有効） |
| `IF Shift` + `R` | IF シフト調整。`R` ボタンで中央値にリセットします（対応機種のみ有効）。 |
| `Fill Width` | フィルター幅表示の調整（対応機種のみ有効） |
| `Scope Enabled` | スコープ機能そのものの有効 / 無効 |

スペクトラム / ウォーターフォール表示エリア自体もクリックやホイール操作で選局・スクロールができます。
無線機がスコープ機能に対応していない場合、スコープ・ウォーターフォールと上記の関連ボタンはすべて非表示になります。
Yaesu 機と Icom 機では Center / Fixed モードの内部値の割り当てが異なりますが、操作方法自体は共通です。

## 6. 送信関連操作

### 6.1 送信

`送信` ボタンを押すと送信状態になります。送信中はボタン表示が `送信中` になります。
もう一度押すと受信状態に戻ります。

`送信` ボタンは通常時も薄緑色の背景で表示されます。送信中は `送信中` の文字が赤く表示されるため、送信状態を画面上で確認しやすくなっています。

送信する前に、以下を確認してください。

- 周波数とバンドが正しいこと。
- モードが正しいこと。
- アンテナまたはダミーロードが適切に接続されていること。
- 送信出力が意図した値であること。
- 無線局の運用条件に合っていること。

### 6.2 TUNE

`Enable ATU` を有効にしてから `TUNE` を押すと、対応無線機でオートアンテナチューナーのチューニングを開始します。
チューニング時は送信状態になることがあるため、必ず接続先と出力条件を確認してください。

### 6.3 CW

`CW` を押すと CW 送信ウィンドウを開きます。
マクロやテキスト送信を行う場合は、送信前に速度、サイドトーン、送信先 VFO、モードを確認してください。

## 7. レピータ / スプリット

`Rpt/Split` を押すと、レピータ、トーン、オフセット、スプリット関連の設定画面を開きます
（左上に `← 戻る` ボタンがあります）。

### 7.1 Repeater Duplex（デュプレックス方向）

- `Simplex` / `Dup+` / `Dup-` / `Auto`: 排他選択（ラジオボタン）です。レピータモードを持つ無線機で、送受周波数差の方向を設定します。
- `Set Offset (MHz)` 欄 + `Set` ボタン: オフセット量を MHz 単位で入力して無線機に送信します（Enter キーでも送信できます）。**この欄はレピータモードを持つ機種専用です。Split（下記）で運用する機種は、Split Mode 側のカスタムオフセット機能を使ってください。**

### 7.2 Split Mode（スプリット）

- `Split On` / `Split Off`: スプリット動作を切り替えます（Duplex のラジオボタン群と同じグループに属し、排他選択です）。
- `QuickSplit`: チェックで簡易スプリットモードを有効にします。無線機がこの機能に対応していない場合、このチェックボックス自体が非表示になります。
- `Set Rpt Tone`（初期状態でチェック済み）: チェックしていると、送信（サブ）VFO 側のトーンを自動的に設定します。Main/Sub VFO の切り替えに対応した機種でのみ有効になります。
- `AutoTrack`: Split On のときのみ有効になります。受信周波数が変わるたびに送信周波数を自動追従させます。送信中は追従を止めます。
- `Offset (KHz)` 欄 + `Split+` / `Split-` ボタン: 受信周波数 ± 指定オフセットを計算し、サブ VFO（および `Tx Freq` 欄）に反映します。実際に無線機へ送信されるのは Split On または QuickSplit On のときだけです。
- `Tx Freq (MHz)` 欄 + `Set` ボタン: 送信周波数を直接指定します。`Split+` / `Split-` を使う場合、この欄への入力は不要です（Enter キーでも送信できます）。

### 7.3 VFO / Main-Sub 操作

- `VFO A` / `VFO B`: 操作対象 VFO を選択します。
- `A=B`: VFO A の内容を VFO B にコピーします。
- `Swap AB`: VFO A と VFO B を入れ替えます（**一部機種は非対応**）。
- `Main` / `Sub`: Main / Sub バンドを選択します（対応機種のみ）。
- `M=>S`: Main の内容を Sub にコピーします。
- `Swap MS`: Main と Sub を入れ替えます。

これらのボタンは、接続した無線機の対応機能に応じて自動的に有効 / 無効が切り替わります。

### 7.4 Repeater Tone（トーン設定）

FM モード以外では「Only available in FM」という注意表示が出ます（FM モードでのみ操作できます）。

- `None` / `Tone` / `TSQL` / `DTCS`: トーンの種類を排他選択します。
- `Tone` コンボ: 送信トーン周波数を選択します（機種の対応トーン一覧から生成）。
- `TSQL` コンボ: トーンスケルチ周波数を選択します。
- `DTCS` コンボ: DTCS コードを選択します。`DTCS Invert Tx` / `DTCS Invert Rx` チェックボックスで送受の反転を指定できます。
- `Set Sub VFO`（Duplex 側にもある同名ボタン）: サブ VFO 側にも同じトーン設定を反映します。**一部機種のみ対応。DTCS では使用できません。**

無線機がトーン / TSQL / DTCS に対応していない場合、該当コントロールは無効化または非表示になります。

## 8. メモリーモード

`Memories` を押すとメモリー画面を開きます（左上に `← 戻る` ボタンがあります）。
無線機がメモリー読み書きに対応している場合、メモリーチャンネルの読み出し、保存、呼び出しなどを行えます。

VFO 表示部の `V/M` ボタンが表示されている場合は、VFO モードとメモリーモードを切り替えられます。

### 8.1 画面構成

- `group` コンボ: メモリーグループを選択します。衛星通信対応機種では「Satellite」グループも選べます。
- メモリー一覧テーブル: メモリー番号、名前、周波数、モード、フィルタ、デュプレックス、トーン設定、DTCS、ステップなど多数の列があり、サブ VFO 側の項目も並びます（列が多いため横スクロールで確認してください）。各行の先頭に `Recall` ボタンがあります。
- `disableEditing` チェック（初期状態でチェック済み = 編集禁止）: チェックを外すとテーブルをダブルクリックで直接編集できるようになります。**このチェックボックス自体は管理者モードで接続している場合のみ操作できます。管理者モードでない場合は常にグレーアウトし、編集はできません。**
- `Start Scan` / `Stop Scan`（対応機種のみ表示、同一ボタンがトグル表示）: メモリースキャンの開始・停止を切り替えます。
- `.csv Import` / `.csv Export`: メモリー内容を CSV ファイルとして読み込み・書き出しします。`disableEditing` を解除しないと `.csv Import` は使えません。
- `checkAllFields`（初期状態でチェック済み）: チェックしていると全列を対象に import / export します。
- `Select Memory Mode` / `Select VFO Mode`（同一ボタンがトグル表示）: メモリーモードと VFO モードを切り替えます。衛星モードだった場合は自動的に解除されます。

### 8.2 メモリーを VFO へ呼び出す（Recall）

1. 目的の行の `Recall` ボタンをクリックします。
2. 無線機がメモリーグループ選択に対応していない場合は、内部でバンドスタック経由の選局に切り替わります。
3. メモリー番号が選択され、VFO の周波数・モードが無線機から再取得されます。
4. まだメモリーモードでなければ、自動的に `Select Memory Mode` の状態に切り替わります。

### 8.3 現在の VFO をメモリーへ書き込む

- 一覧テーブル上で右クリックするとコンテキストメニューが開きます。
  - `Use Current`: 選択中の行を、現在の VFO の内容（周波数・モード・トーン・DTCS 等）で上書きします。名前は仮に `<UPDATED>` になります。
  - `Add Current`: 一覧の末尾に新規行を追加し、現在の VFO の内容を書き込みます。名前は仮に `<NEW>` になります。
- `disableEditing` を解除している場合は、セルを直接ダブルクリックして値を書き換えることもできます（Kenwood / Yaesu 機のみ、無線機への書き込みコマンドが発行されます）。

### 8.4 メモリーの削除

一覧テーブル上で削除操作を行うと、該当メモリーに削除フラグを付けて無線機（衛星メモリーの場合は衛星メモリー機能）へ送信します。

### 8.5 注意事項

- CSV インポート時は、周波数・DTCS コード・スケルチコードなどの書式が自動補正されます（周波数は 6 桁、DTCS は 3 桁ゼロ埋めなど）。
- Icom 機など、無線機によってはメモリーの直接書き込み・選択コマンドを持たない場合があります。その場合、対応するボタンや編集操作が実質的に機能しないことがあります。

## 9. 終了

1. 必要に応じて送信状態を解除します。
2. 必要に応じて `Power Off` を押します。
3. `終了` ボタンを**ダブルクリック**するか、ウィンドウを閉じてアプリケーションを終了します。
   `終了` ボタンは誤操作防止のためシングルクリックでは反応しません。

この版では、終了時に発生していた Qt audio 系のクラッシュを回避する修正が入っています。

### 9.1 設定変更時の終了確認ダイアログ

`Settings` を変更した後、`保存` を押さずに終了しようとすると、英語の確認ダイアログ
（`Settings have changed since last save, exit anyway?`）が表示されます。

- `Yes`: 変更を保存せずに終了します。
- `Save`: 設定を保存してから終了します。
- `No`: 終了をキャンセルし、メイン画面に戻ります。
- `Don't ask me again` にチェックを入れると、次回以降このダイアログを表示せずに終了できるようになります。この設定は自動的に保存されます。

## 10. トラブルシューティング

| 症状 | 確認すること |
|---|---|
| 接続できない | 無線機、接続方式、ポート、CI-V アドレス、ネットワーク設定を確認します。 |
| ボタンが無効 | 無線機がそのコマンドに対応しているか確認します。 |
| 周波数アップ / ダウンのステップが意図と違う | 周波数表示の目的の桁をクリックしてから `▲` / `▼` を押します。 |
| WF レベルが合わない | `WF` スライダーでウォーターフォール表示を調整します。 |
| 音声が入出力されない | `Settings` の音声入力 / 出力デバイスと Windows のプライバシー設定（マイクへのアクセス許可）を確認します。 |
| TUNE が動作しない | `Enable ATU`、無線機のチューナー対応、送信条件を確認します。 |

## 11. 安全上の注意

このアプリは無線機を送信状態にできるソフトウェアです。
送信、TUNE、CW、スプリット、レピータ設定を操作する前に、必ず周波数、出力、アンテナ、免許条件、周囲への影響を確認してください。
